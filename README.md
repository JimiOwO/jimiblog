Source code for my personal website—a minimalist portfolio, blog, and experimental space for modern web technologies.

## Overview

`pengui.dev` is a content-first personal site built with a focus on high performance, maintainability, and clean code. It serves as a testing ground for modern web standards and the Astro ecosystem.

## Tech Stack

- **Framework**: Astro (Islands Architecture)
- **Styling**: Vanilla HTML5 & CSS3
- **AI Assistance**: Gemini 2.0 (Architectural optimization)
- **Deployment**: GitHub Pages via GitHub Actions
- **Domain**: [pengui.dev](https://pengui.dev)

## Key Features

- **Static Site Generation (SSG)**: Pre-rendered pages for near-instant loading and SEO optimization.
- **Performance-First**: Minimal client-side JavaScript for a lightweight footprint.
- **Responsive Design**: Fully adaptable layouts across mobile and desktop devices.
- **AI-Refined**: Core logic and structural decisions optimized with AI support.

## Local Development

### Prerequisites
- Node.js (LTS recommended)

### Setup
```bash
# Clone the repository
git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)

# Install dependencies
cd your-repo-name
npm install

# Start the development server
npm run dev
/The development server will be available at http://localhost:4321/.

Deployment
Continuous Deployment (CD) is configured via GitHub Actions. Any push to the main branch automatically triggers a build and deploys the updated static files to GitHub Pages.
