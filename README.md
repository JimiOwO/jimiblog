# pengui.dev

Source code for my personal website — portfolio, blog, and experimental space for modern web technologies.  
个人网站源代码仓库：作品集、博客与现代 Web 技术实验空间。

🔗 **Live Site / 在线访问**  
https://pengui.dev  

---

## Overview / 项目简介

A minimal, high-performance portfolio and blog built with a content-first philosophy.  
Design principles: simplicity, speed, and maintainability.

一个以内容为核心的极简个人网站，强调性能、可维护性与现代 Web 标准。

---

## Tech Stack / 技术栈

| Component | Technology |
|-----------|------------|
| Framework | Astro (Islands Architecture) |
| Styling | HTML5 & CSS3 (Vanilla) |
| AI Assistance | Gemini 4o |
| Deployment | GitHub Pages (via GitHub Actions) |
| Domain | pengui.dev |

---

## Features / 特性

- **Static Site Generation (SSG)** — Optimized build output with minimal client-side JavaScript  
- **Performance-Oriented** — Lightweight architecture and fast loading times  
- **Responsive Design** — Fully adaptable across mobile and desktop devices  
- **AI-Assisted Development** — Code optimization and structural refinement supported by Gemini 4o

Deployment / 部署
Continuous deployment is configured via GitHub Actions.
Any push to the main branch triggers automatic build and deployment to GitHub Pages.

推送至 main 分支后，将自动构建并部署至 GitHub Pages。
