使用 Astro 静态站点生成器构建，CSS 变量设计系统统一视觉风格。导航配置集中管理，兴趣卡片支持 3D 倾斜悬停动效，地球仪组件基于 Three.js 实现访问地点可视化。全站支持中英双语切换与深色模式。

Built with Astro SSG. A CSS variable-based design system unifies the visual language. Navigation is centrally configured. Interest cards feature 3D tilt-hover effects, and the globe component uses Three.js to visualize visited places. Full bilingual (zh/en) and dark mode support throughout.
