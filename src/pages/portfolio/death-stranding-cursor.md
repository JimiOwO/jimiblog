A Windows cursor theme inspired by the UI style of Hideo Kojima's game "Death Stranding." Features a minimalistic line design, 15 cursor states, Ultra-HD 256×256 resolutio. Also features animated icons.

## How to Install

- Download the cursor pack (ZIP) above.
- Extract the ZIP, right click on install.inf and select "Install".
- In “Mouse Properties” → “Pointers” → “Scheme”, select “SD1.3”.
- Click Apply and enjoy!
